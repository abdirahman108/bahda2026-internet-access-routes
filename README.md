# Amoud University BAHDA-2026 analysis code

Analysis scripts for papers based on the Borama Amoud Household Development Assessment (BAHDA) 2026 survey.

| Folder | Paper |
|---|---|
| `p15_internet_access_modes` | Paper 15: Ways households access the internet in Borama District |

The BAHDA-2026 household microdata are held by Amoud University and are not included in this repository.
